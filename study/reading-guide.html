Credibility Lab — 阅读对照组指南 / Reading Group Guide

开始前 / Before starting

请研究人员填写：参与者编号____；前测A/B____；后测为另一卷；联系及交回渠道____。同一个人全程使用同一匿名编号，不填姓名或联系方式。A/B是试卷名称，不固定代表前后测。

The researcher supplies your anonymous code, first form and return channel. Use the same code throughout. A/B identify forms, not stages.

先阅读参与者说明并完成知情同意。你可以跳题、询问操作方法或停止参加；退出及数据处理安排以参与者说明为准。现有指南建议预留40–50分钟，这是预计时长，不是限时。独立作答；如需翻译或语言协助，请在开始前说明并报告实际使用情况。如果已经做过网站训练或这些试卷，请先告知研究人员。

Read the information sheet and complete consent before starting. Participation is voluntary. Allow approximately 40–50 minutes as a planning estimate. Work individually; report translation, help and any previous exposure to the training or forms.

操作顺序 / Sequence

前测 → 指定阅读 → 后测 → 交回文件及结束说明

Pre-test → Assigned reading → Post-test → Return files and debrief

1. 前测 / Pre-test

只打开分配给你的A卷或B卷。填参与者编号，Stage选择 Pre-test。每卷6题：选择判断、填写0–100信心值，并尽量用1–2句话说明证据或理由。你可以跳过不愿回答的题目。

Open only your assigned form, enter your code and select Pre-test. For each of six items, choose a judgement, rate confidence and briefly explain your reasoning. You may skip items.

  • Supported：有证据支持——现有信息支持帖子实际提出的说法。
  • Misleading：具有误导性——说法让人对证据产生误解。
  • Insufficient evidence：证据不足——信息不足以判断。

每题自带的两份来源说明可以看一份、两份或都不看。此时不要打开阅读活动或另一套试卷，也不要索取正确答案反馈。

You may consult either, both or neither assessment source note. Do not open the reading activity or the other form yet, or seek correctness feedback during assessment.

点击 Submit responses → Download a backup，确认JSON已保存再关页面；若版本显示 Download responses，使用该下载按钮。保留原前测文件，之后不要覆盖。

Submit and download the JSON backup; preserve the original pre-test file.

2. 指定阅读 / Assigned reading

保存前测后，打开阅读材料。读完长城和金星两个案例、来源说明，以及 What the evidence shows 解释。按材料指引阅读，完成后告诉研究人员，再进入后测。需要时记录开始、结束时间，并报告帮助和技术问题。

Read both cases, their source notes and the evidence explanations. Tell the researcher when finished. Record reading times if requested and report assistance or problems.

阅读组使用这份材料，不进入互动信息流训练；无需创建个人主页或下载网站训练记录。

Use the assigned reading rather than the interactive training. No profile or website training export is required.

3. 后测 / Post-test

前测A则后测B；前测B则后测A。填同一编号，Stage选 Post-test。按与前测相同的要求作答，包括可选查阅题目来源说明。提交并下载独立的后测JSON。

Use the other form with the same code and select Post-test. Follow the same instructions and source-note options, then save the separate JSON file.

不需要刻意提高分数或改变答案。不要把A、B都在前后各做一遍，也不要重做来替换答案。若误做了额外试卷，请保留文件并如实说明顺序。

There is no requirement to improve. Do not complete both forms at each stage or repeat a form to replace responses. Report accidental extra exposure and retain the files.

4. 交回与结束 / Return and debrief

交回两份附件：前测JSON、后测JSON。例如 P12-Pre-test-A.json 和 P12-Post-test-B.json；请使用自己的编号和实际卷序。

Return two JSON attachments: your pre-test and post-test, using your own code and actual form order.

即使看到在线回执，也必须下载并交回文件，自动接收可能失败。 若显示 Receipt unavailable，先保持页面打开并下载备份。无法保存时联系研究人员。不要自行编辑JSON答案或阶段，有误请直接说明。

Download and return both files even if a receipt appears. If delivery fails, save a backup and contact the researcher. Report mistakes rather than editing the JSON.

完成后联系研究人员获取结束说明。阅读组不填写网站体验问卷，因为没有接受网站互动训练。

Contact the researcher for the debrief. Reading-group participants do not complete the website experience questionnaire.

完成检查 / Final check

  • [ ] 阅读后做另一卷后测 / Other form after reading.
  • [ ] 两份JSON已交回，或已报告困难 / Both files returned or problems reported.
  • [ ] 已报告额外试卷接触、翻译或帮助 / Extra exposure and assistance reported.
